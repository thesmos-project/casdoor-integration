# Security

`v4.15.0-thesmos.2` is the supported release, published as a signed image. The
[security review](docs/SECURITY-REVIEW.md) lists the advisories checked against
its source, and the [release notes](docs/RELEASE-NOTES.md) list security-relevant
changes.

Do not disclose credentials or suspected vulnerabilities through public issues.
For Casdoor vulnerabilities, follow the original project's
[security guidance](https://github.com/casdoor/casdoor/security).

For integration-specific findings, use **Security → Report a vulnerability**
in this repository. GitHub private vulnerability reporting is enabled.

A maintainer decides whether and when to report an issue to the Casdoor
project and when to publish a fix.
