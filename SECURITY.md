# Security

This repository currently contains an initial project scaffold. It has no
supported production releases or published container images.

Do not disclose credentials or suspected vulnerabilities through public issues.
For Casdoor vulnerabilities, follow the original project's
[security guidance](https://github.com/casdoor/casdoor/security).

For integration-specific findings, use GitHub private vulnerability reporting
when the repository's Security tab provides that option. A project-specific
private reporting channel must be established before the first release.

No upstream security report is submitted automatically. Disclosure and release
decisions require explicit maintainer review.
