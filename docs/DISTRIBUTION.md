# Image source and notices

Casdoor remains the upstream product. Its Apache licence and notices are retained.
Dependencies keep their own licences; the image's application licence label does
not relicense its system libraries, browser bundles or fonts.

The builder records the production Go import closure and toolchain, the Vite
module graph including CSS/fonts, and every dependency path in the exact bundled
Swagger UI source maps. The frontend inventory build must match the normal build's
generated bytes. CSS preprocessing dependencies are included through Vite's watched
files because CSS imports can be consumed outside Rollup's module graph.
Inventories conservatively retain nested/vendor notices and licence directories.

The previously pinned LDAP message module contained a GPLv2 licence. The sixth
patch selects its author's subsequent MIT revision, `8d785c64d1c87d6fa9c95591edf9d8abc603a34c`.
Its parent is the earlier pinned commit and its only changed file is LICENSE;
every non-licence file compares byte for byte. The original MIT notice is retained.
FreeType-Go uses its permitted FreeType License option, with the required credit
in NOTICE. Covered MPL Go modules have their exact checksum-verified source ZIPs
in the image alongside their notices.

`swagger.lock.json` identifies Swagger UI 4.1.0. Its assets must match the npm
archive byte for byte. The source package lock and dependency archive integrity
values determine the bundled dependency versions. The missing `.LICENSE.txt`
files referenced by the original bundles are supplied with combined notices;
the original JavaScript is unchanged.

Some npm/Go archives omit a separate licence file. `licenses/overrides.json`
records recovered originals, hashes and provenance. Where the original grant
lives in a README or parent project, that evidence accompanies full licence
terms. Two npm project notices are from pinned upstream revisions rather than
an unavailable npm gitHead. The `format` package's original copyright/MIT grant
accompanies generic MIT terms because its author's linked licence page was
unavailable. These distinctions require review before accepting distribution.

`os.lock.json` identifies each installed system package, version, licence,
source origin and Alpine commit. The corresponding source kit includes exact
APKBUILD recipes, patches/configuration and archives verified by `abuild` against
those recipes' checksums. Recipes with no remote source retain all their source
files. Source copyrights remain in the files and archives, with standard
licence terms alongside them. No registry or GitHub credentials enter source-kit
containers or image layers.

To extract the notices and matching system package sources without starting the
auth server:

```sh
container=$(docker create "$CASDOOR_IMAGE")
docker cp "$container:/licenses" ./image-licenses
docker rm "$container"
```

Image publication checks hashes, notice coverage, system package identity and
source-kit coverage before pushing. These checks establish reproducible coverage;
they do not constitute independent legal or security approval. Manual candidate
acceptance must still identify its reviewer and evidence. Stable production
acceptance is a separate record.

The publishing workflow attaches BuildKit's SBOM/provenance and a separately
signed SPDX inventory from these image manifests. The latter includes dependencies
hidden inside compiled browser/CSS/font assets. Unresolved licence metadata stays
`NOASSERTION`; full notices are the licence evidence. Both the image signature and
SPDX attestation are verified against the publishing workflow's OIDC identity.

The source archives increase image download/storage size. They are inactive files
and add no service or JVM/runtime dependency.
